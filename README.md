                                     📱📊 Mobile Data Analysis & Power BI Dashboard 📱📊

An interactive **Power BI dashboard** for analyzing mobile phone specifications, companies, models, features, and launch prices to identify product and pricing patterns.

## 📌 Project Overview

This project analyzes mobile phone data using **Power BI, Excel, DAX, and data visualization techniques**.

The dashboard provides interactive insights into mobile brands, models, RAM, camera specifications, processors, battery capacity, weight, screen size, and launch prices.

The report also includes **price analysis by company and model**, feature-vs-price analysis, currency-based price comparison, and a detailed matrix of mobile specifications.

## 🎯 Project Objectives

* Analyze mobile phone models across different companies
* Compare launch prices across companies and models
* Analyze RAM and camera specifications
* Examine processor availability across mobile models
* Study the relationship between mobile features and price
* Create interactive dashboards using Power BI
* Apply DAX for calculated measures and analysis

## 💡 Key Insights

* Different companies have significantly different numbers of models in the dataset.
* Mobile specifications such as RAM, camera, processor, battery, and screen size can be analyzed alongside pricing.
* Launch prices vary considerably between companies and models.
* Feature-level analysis helps compare hardware specifications with mobile pricing.
* Currency selection enables the same pricing analysis across multiple markets.
